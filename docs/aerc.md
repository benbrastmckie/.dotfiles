# aerc

aerc is the terminal mail client. It reads the shared `~/Mail` maildir through a notmuch
backend and sends through SMTP. Everything it loads is generated by Home Manager from
`modules/home/email/aerc.nix`; nothing under `~/.config/aerc/` is edited by hand.

| Rendered file | Declared in `aerc.nix` as | Holds |
|---------------|---------------------------|-------|
| `~/.config/aerc/aerc.conf` | `programs.aerc.extraConfig` | UI, viewer, compose, filters, openers |
| `~/.config/aerc/binds.conf` | `programs.aerc.extraBinds` | every key mapping |
| `~/.config/aerc/stylesets/amber` | `programs.aerc.stylesets.amber` | colours |
| `~/.config/aerc/accounts.conf` | `home.file` | one block per account tab |
| `~/.config/aerc/querymap-<account>` | `home.file`, via `mkQuerymap` | that account's sidebar folders |

After any edit, rebuild and restart aerc:

```sh
home-manager switch --flake .#benjamin
```

Related: `docs/email-workflow.md` covers the agent triage wrappers and outgoing mail through
msmtp; `docs/himalaya.md` covers mbsync and the Himalaya CLI.

## Accounts and tabs

Each `[name]` block in `accounts.conf` becomes one tab in the strip at the top, in file order.
The tab title is the account name followed by its INBOX unread count, e.g. `gmail (44)`.

| Tab | Address | Maildir subtree | Sending | Mail check from inside aerc |
|-----|---------|-----------------|---------|-----------------------------|
| `gmail` | `benbrastmckie@gmail.com` | `~/Mail/Gmail` | `smtp.gmail.com:465`, app password from the keyring | every 10 min, and on `u` |
| `logos` | `benjamin@logos-labs.ai` | `~/Mail/Logos` | Proton Bridge at `127.0.0.1:1025` | not wired; the systemd `mail-sync-timer` covers it |

Both accounts share one maildir root and one notmuch database. An account's sidebar is a set of
notmuch queries (its query-map), each scoped with a `folder:` token; the raw maildir tree is
hidden by `folders-exclude`, and `folders-sort` fixes the sidebar order.

### Adding an account

1. `modules/home/email/mbsync.nix`: add the `IMAPAccount`, stores, channels, and a `Group`,
   syncing into `~/Mail/<Name>/`.
2. `modules/home/email/mail-sync.nix`: teach the `mail-sync` wrapper the new group so the timer
   syncs it.
3. `modules/home/email/aerc.nix`:
   - add a `[name]` block to `accounts.conf` (copy `[logos]`; set `from`, `archive`, `outgoing`,
     `outgoing-cred-cmd`, `query-map`);
   - add a `querymap-<name>` file with `mkQuerymap { prefix = "<Name>"; archiveName = "..."; }`;
   - add `~^<Name>` to `foldersExclude`.
4. `modules/home/email/notmuch.nix`: add the address to `other_email` and the account tag to
   the `postNew` hook.
5. `modules/home/email/msmtp.nix`: add the matching account if other tools send as it.
6. Store the password in the keyring under the service name `outgoing-cred-cmd` looks up.

## Theme

The `amber` styleset uses the terminal palette from `config/wezterm.lua`, so the selected aerc
tab matches the terminal's own active tab.

| Role | Colour |
|------|--------|
| Accent: selected tab, selected folder, flagged, headers in the viewer | `#e5b566` |
| Unread | `#f5f5f5`, bold |
| Read | `#909090` |
| Replied / forwarded | `#7e8d50` / `#7dd5cf` |
| Marked | black on `#6c99ba` |
| Selection background | `#303030` |
| Errors | `#ac4142` |
| Borders | `#404040` |

Backgrounds are set only on selections and bars, so the terminal's background opacity shows
through. To change a colour, edit `stylesets.amber`; `man aerc-stylesets` lists every style
object. To try one of the stylesets bundled with aerc (`catppuccin`, `dracula`, `nord`,
`solarized-dark`, ...), set `styleset-name` under `ui`.

Layout choices, all under `ui` in `aerc.nix`:

- Columns are flags, sender, subject, date, with the date flush right.
- Threading is on. Replies nest under their parent, and a repeated subject is left blank.
- The sidebar is 24 columns and ordered by `foldersSort`: live views, storage, then triage.

## Key mappings

Every mapping below is declared in `extraBinds`. A key that is not listed is unbound: aerc's
stock bindings are not loaded. `:` opens the command line everywhere except while composing or
in a terminal tab, where it is `Ctrl-x`. Inside aerc, `?` shows the live bindings for the
current context, which is the check that this table is accurate; so is reading
`~/.config/aerc/binds.conf`.

### Everywhere

| Key | Action |
|-----|--------|
| `Ctrl-n` / `Ctrl-p` | Next / previous tab |
| `Ctrl-t` | Open a terminal tab |
| `?` | Show the bindings for this context |

### Message list

| Key | Action |
|-----|--------|
| `j` / `k` | Next / previous message |
| `g` / `G` | First / last message |
| `Ctrl-d` / `Ctrl-u` | Half page down / up |
| `Ctrl-f` / `Ctrl-b` | Full page down / up |
| `J` / `K` | Next / previous folder |
| `Tab` / `Shift-Tab` | Next / previous tab |
| `Enter` | Open the message (in Drafts: reopen the draft for editing) |
| `c` | Compose |
| `r` / `R` | Reply / reply all |
| `f` | Forward |
| `a` | Archive, no prompt |
| `A` | Mark everything in the folder, then archive it all after a prompt |
| `d` | Delete after a prompt |
| `D` | Delete after a single prompt, skipping aerc's own confirmation |
| `*` | Toggle the `flagged` tag |
| `t` | Add or remove tags (`:modify-tags `, then type `+tag -tag`) |
| `T` | Toggle a tag (`:toggle-tag `, then type the tag) |
| `/` | Search; `n` / `N` jump to the next / previous result |
| `v` | Filter the list (`:filter `, then type the terms) |
| `V` | Clear the search or filter |
| `Space` | Toggle selection |
| `x` / `X` | Toggle selection and move down / up |
| `m` | Mark (`:mark `, then type flags such as `-a` or `-t`) |
| `M` | Unmark everything |
| `zt` | Toggle threading |
| `zc` / `zo` | Fold / unfold the thread under the cursor |
| `u` | Check mail using the account's check-mail command |
| `$` | Sync Gmail now through `mail-sync gmail` |
| `q` | Quit aerc |

Deletes propagate: mbsync runs with `Expunge Both`, so a message deleted here is removed from
the server on the next sync. A folded thread is archived or deleted as a whole.

### Triage views

In `Proposed-Delete`, `Proposed-Archive`, and `Proposed-Unsure` these replace the normal keys.
They only retag and queue the message for the confirmed-mutation wrappers described in
`docs/email-workflow.md`; nothing is moved or deleted by the keypress.

| Key | Where | Action |
|-----|-------|--------|
| `d` | Proposed-Delete, Proposed-Unsure | Confirm for deletion |
| `a` | Proposed-Archive, Proposed-Unsure | Confirm for archiving |
| `k` | all three | Keep: retag `proposed-keep`. Moving up needs `Ctrl-u` or `:prev` here. |

### Composing

While editing headers or in the editor:

| Key | Action |
|-----|--------|
| `Ctrl-j` / `Ctrl-k` | Next / previous field |
| `Ctrl-n` / `Ctrl-p` | Next / previous tab |
| `Ctrl-x` | Open the aerc command line |

On the review screen, after leaving the editor:

| Key | Action |
|-----|--------|
| `y` | Send; when replying, also archive the message replied to |
| `e` | Back to the editor |
| `p` | Postpone to Drafts |
| `a` / `d` | Attach / detach a file (type the path) |
| `n` or `q` | Abort |

### Terminal tabs

| Key | Action |
|-----|--------|
| `Ctrl-n` / `Ctrl-p` | Next / previous tab |
| `Ctrl-x` | Open the aerc command line |

### Changing a mapping

Edit the matching attribute set under `extraBinds` in `modules/home/email/aerc.nix`: `global`,
`messages`, `view`, `compose`, `"compose::editor"`, `"compose::review"`, `terminal`, or a
folder-scoped set such as `"messages:folder=Drafts"`. The left side is the key sequence, the
right side the command with `<Enter>` to run it, or a trailing space to leave the command line
open for typing. Update the table above in the same change.

## Troubleshooting

- **Rows reading `could not get MessageInfo: ... no such file or directory`**: the notmuch index
  is behind the maildir. Run `notmuch new --no-hooks`. If that prints `unable to load config
  file`, the generated notmuch config is invalid; see the `new.ignore` comment in
  `modules/home/email/notmuch.nix`.
- **`u` reports `no command specified`** on the logos tab: check-mail is not wired for that
  account; the timer syncs it.
- **Colours look wrong**: the styleset uses 24-bit colour, which WezTerm and Kitty support.
