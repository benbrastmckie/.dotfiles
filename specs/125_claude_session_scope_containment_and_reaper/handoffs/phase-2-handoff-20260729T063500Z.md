**Key Decisions Made**:
- Added explicit unparsable-PID-list and PID-vanished-mid-read detection (both skip the unit)
  beyond the plan's numbered steps, to satisfy the binding constraint's "any ambiguity ... skips
  the unit" clause literally for those two named cases.
- Nix string escaping for the bash empty-string case pattern (`''` inside an indented `''...''`
  Nix string) required `'''` in the source — verified correct via a standalone `nix eval` before
  trusting it in the real module.
- Decoy construction for the live-session test required `bash -c 'sleep 600; true'
  claude-decoy-marker` rather than `exec -a claude-decoy sleep 600`: `exec -a` fails under
  NixOS's multi-call coreutils wrapper (`coreutils: unknown program 'claude-decoy'`), and a bare
  `bash -c 'sleep 600'` gets tail-call exec-optimized by bash into a bare `sleep` process that
  loses any marker. Appending `; true` forces bash to fork a real child and keep running itself
  (with a claude-containing cmdline) instead of exec'ing away.

**Deviations from Plan**: None (only additive strengthening beyond the letter of the ambiguity
spec, documented inline in the plan's Phase 2 task list).

**What NOT to Try**:
- `exec -a <name> sleep ...` for decoy argv0 spoofing — breaks under this host's coreutils
  wrapper.
- A single-command `bash -c 'sleep N'` for a decoy expected to keep bash's own cmdline visible —
  bash's exec optimization silently replaces it with `sleep`.
