# Phase 4 Handoff: Extract the shared wrapper builder and rewire the module

**Immediate Next Action**: Phase 5 — author the standalone flake.nix.

**Current State**: Phase 4 completed. `packages/sapience-flake/lib/wrappers.nix` is a new,
parameterized builder (`{ pkgs, lib, stateDir, host, backend, model, memoryFiles, tokenFile,
backgroundSync, syncInterval, ollamaEnabled ? false }`) returning
`{ sapience, sf1, sapience-bootstrap, python, runtimePath, requiredPayload, optionalPayload }`
with zero `config.*`/`cfg.*` Nix-attribute dependencies. The module now does
`wrappers = import ../lib/wrappers.nix { ... cfg values ...; ollamaEnabled = config.services.ollama.enable; }`
and `inherit (wrappers) python runtimePath requiredPayload optionalPayload;`, reusing the
builder's constants for its own non-wrapper config glue instead of duplicating them.

**Key Decisions Made**: Expanded the builder's return beyond the plan's literal
`{ sapience, sf1, sapience-bootstrap }` to also export `python`/`runtimePath`/
`requiredPayload`/`optionalPayload`, because those four constants are read not only by the three
wrappers but also by the module's own `home.activation.sapiencePayload` (payload lists),
`home.activation.sapienceMcpServer` (`python`), and the `sapience-sync` systemd service
(`runtimePath`) — a literal "move" would have left those three call sites broken. This keeps
exactly one definition of each shared between the wrappers and the module.

**Deviations from Plan**: Three, all annotated inline on Phase 4's checklist — see the plan file.
Summary: (1) builder return set expanded as above; (2) two irreducible `config.json` filename
string-literal hits remain in the `grep -nE '\bcfg\.|\bconfig\.'` sweep (the vendor's real
filename, not a stray attribute access); (3) the ticker-gate comment's wording changed (not its
logic) when moved, to drop `cfg.`/`config.` substrings for (2).

**What NOT to Try**: Do not try to eliminate the two `config.json` grep hits by renaming — that
file name is the vendor's own, fixed on disk; it cannot be changed from this side.
